# MATLAB support

This directory provides a MATLAB lane alongside the Python/PyBaMM electrochemical reference workflow.

## Deliberate division of responsibility

- **Python/PyBaMM** is the primary electrochemical implementation. It generates the SPM truth trajectories, internal particle-state variables, observer data, and research metrics.
- **MATLAB** provides a second environment for reproducible CSV invariant checks, figures, and a small control-oriented reduced-order pack simulation.
- The MATLAB reduced-order model is a sanity check for pack-level trends. It is not a replacement for the PyBaMM SPM and must not be presented as an independent DFN/SPM validation.

This avoids duplicating a mature electrochemical solver under the three-day project constraint while still making the control and analysis path portable to MATLAB/Simulink.

## Requirements

MATLAB R2019b or newer is recommended. The scripts use base MATLAB functionality only. No Simulink toolbox is required.

MATLAB is not installed in the current development environment, so these scripts are committed as **not yet executed here**. Results generated by MATLAB must be clearly labelled as MATLAB checks or reduced-order sanity simulations.

## Run from MATLAB

From the repository root:

```matlab
cd matlab
validate_saved_results
plot_saved_results
run_reduced_pack_simulation
```

From Python, the portable preflight contract check can be run even when MATLAB is unavailable:

```bash
python experiments/validate_matlab_contract.py
```

The first script reads the committed Python CSV artifacts and independently checks:

- common series current,
- pack voltage equal to the sum of cell voltages,
- zero-net ideal balancing transfer,
- cell-current decomposition,
- SOC propagation using actual saved time intervals,
- consistency of final spread metrics.

The plotting script creates additional figures under `results/plots/`.

The reduced-order simulation uses four heterogeneous Thevenin 1-RC cells with the same current profile and pack heterogeneity as the Python baseline. It is intended to verify qualitative effects such as the weakest cell producing the lowest voltage and the largest SOC divergence. It writes:

- `results/csv/matlab_reduced_pack_trajectories.csv`
- `results/csv/matlab_reduced_pack_summary.csv`
- `results/plots/matlab_reduced_pack.png`

`REQUIREMENTS.md` maps each MATLAB entry point to its inputs, changed outputs, and acceptance status. The Python contract checker verifies that this mapping is present in the source and documentation. It does not replace MATLAB execution.

## Research reporting rule

Do not combine MATLAB reduced-order numbers with PyBaMM electrochemical numbers in one table without labelling the model source. The first MATLAB comparison should be qualitative and model-structure-aware. Quantitative cross-model claims require calibration and a documented parameter-identification procedure.
